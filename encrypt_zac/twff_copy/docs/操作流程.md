# 傻瓜式操作流程

> 前提：你的终端提示符是 `(mytest)`，说明 conda 环境已经激活。
> **不要用 `$PY` 这种变量**（忘了赋值就会报「&后面的表达式生成无效的对象」），直接写 `python`。
>
> 下面的命令都用**从 `Proofflow` 起的相对路径**。开始前先确保终端在 `Proofflow`
> 目录下（即本项目的根仓库目录，例如 `D:\hacku\teamproject\Proofflow`）。

---

## 第 0 步：进目录

```powershell
cd encrypt_zac\twff_copy
```

---

## 第 1 步：清掉旧日志，重新开始

我测试时留下的 `audit.json` 先删掉（第一次跑可以跳过）：

```powershell
Remove-Item audit.json,anchor.json -Force -ErrorAction SilentlyContinue
```

---

## 第 2 步：建基线（起链）

```powershell
python chainlog.py init --file textfile.txt --log audit.json
```

**看到这样就对了：**

```
已创建日志 audit.json
  session_id : xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  监视目标   : textfile.txt
  起始事件数 : 2
```

---

## 第 3 步：开监视器（这个窗口会被占住）

```powershell
python chainlog.py watch --file textfile.txt --log audit.json --interval 1.0
```

**看到这样就对了：**

```
已固化链外锚点 anchor.json
  head_hash   : 3f2a1b4c...
  chain_length: 2
开始监视 textfile.txt（每 1.0s 检查一次，Ctrl+C 停止）
日志: audit.json   session: 3f2a1b4c…
```

⚠️ **这个窗口别关，它会一直挂着监视。** 接下来去开**第二个** PowerShell 窗口做第 4 步。

---

## 第 4 步：改文件（新开一个终端！）

新窗口里执行（同样从 `Proofflow` 目录起）：

```powershell
cd encrypt_zac\twff_copy
```

然后改 `textfile.txt`。最省事的办法是用记事本：

```powershell
notepad textfile.txt
```

随便加几个字，**保存**，关掉记事本。等 1～2 秒。

**回到第 3 步那个窗口**，应该会多出一行：

```
[2026-10-03T06:31:01Z] content_modified  94 chars (+50)  c27cd038bc4a…  _hash=35150aafceed…
```

再改一次、保存，就会再多一行。**每改一次记一条**，这就是哈希链。

---

## 第 5 步：停止监视

回到监视器窗口，按 **Ctrl + C**。

**看到这样就对了：**

```
已停止。共 8 条事件，head_hash=b2e6c8832ae9edbd13da64fd…
```

（如果窗口没反应，直接关掉也行——已记录的事件都在磁盘上，链依然完整，只是少一条 `session_end`。）

---

## 第 6 步：验证链没被篡改

任意窗口执行：

```powershell
python chainlog.py verify --log audit.json --file textfile.txt
```

**看到这样就对了：**

```
  ✅ event[0] ('chain_init') 3707849b2173d124…
  ✅ event[1] ('content_baseline') af0d54487dfb21bf…
  ✅ event[2] ('watch_start') 826e011f3438548a…
  ✅ event[3] ('content_modified') 35150aafceed7706…
  ...
  ✅ head_hash b2e6c8832ae9edbd13da64fde23af45d…
  ✅ 正文与记录一致 c27cd038bc4a66aa…

✅ 完整  8 条事件，链未被篡改
```

## 第 7 步：看时间线

```powershell
python chainlog.py show --log audit.json
```

会打印每条事件的时间、类型、字符数、增量和 `_hash`。

## 第 8 步（可选）：亲手篡改一次，看它是怎么被抓住的

### 8a. 先改正文，验证会失败

```powershell
Add-Content textfile.txt "someone tampered here"
python chainlog.py verify --log audit.json --file textfile.txt
```

**看到这样就对了：**

```
  ❌ 正文与记录不一致
     记录 c27cd038bc4a66aa…
     实际 9f1b7e2d3c4a8f01…
```

### 8b. 再篡改日志本身，链会崩

```powershell
python examples\tamper_demo.py
```

**看到这样就对了：**

```
  1 改事件字段 (event[3])          ❌ 抓到：event[3] ('content_modified') 哈希不匹配
  2 删除一条事件 (event[4])        ❌ 抓到：event[4] ('content_modified') 哈希不匹配
  3 调换顺序 (event[5]↔[6])       ❌ 抓到：event[5] ('content_deleted') 哈希不匹配
  4 追加伪造事件                   ❌ 抓到：event[8] ('content_modified') 哈希不匹配
  5 篡改后重算整条链                ✅ 未发现（链自洽）   ← 必须靠 anchor.json 才能发现
```

### 8c. 看"重算链"为什么只能靠链外锚点

```powershell
python examples\rechain_demo.py
```

## 常见问题

**Q: 报 `&后面的表达式生成无效的对象`**
`$PY` 是空的。别用变量，直接写 `python`。

**Q: 报 `python 不是内部或外部命令`**
conda 环境没激活。看提示符里有没有 `(mytest)`；没有就先 `conda activate mytest`。

**Q: watch 窗口一直不出现新行**
① 确认改的是**同一个** `textfile.txt`（注意别改到 `textfile1.txt`）；② 确认保存了（记事本要按 Ctrl+S）；③ 文件内容真的变了（改成一样的内容不会记账）。

**Q: 中文乱码**
不用管内容编码，程序按二进制读文件、按 UTF-8 解码展示。预览里的 `?` 是 BOM 或不可打印字符的占位符。

**Q: 我想监视别的文件**
把 `--file textfile.txt` 换成你的文件路径即可，`--log` 也建议换一个名字，例如：
```powershell
python chainlog.py init --file myessay.txt --log essay-audit.json
python chainlog.py watch --file myessay.txt --log essay-audit.json
```

**Q: 每次只记一条，我连改好几下怎么办**
轮询间隔默认 1 秒，间隔内的多次修改会合并成一条事件。想更细就调小：
```powershell
python chainlog.py watch --file textfile.txt --log audit.json --interval 0.2
```
